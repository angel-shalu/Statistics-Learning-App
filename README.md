# 📊 Statistics Learning App

✨ Learn Statistics the smart way — with interaction and visuals!

An interactive Streamlit web app to explore Descriptive & Inferential Statistics using real data, formulas, and graphs.


# 🚀 What You Can Do

✔ Enter your own data or upload a CSV/Excel file
✔ Instantly compute statistical measures
✔ Visualize distributions and results
✔ Learn formulas alongside calculations


# 📌 Topics Covered

# Descriptive Statistics

Mean, Median, Mode

Variance, Standard Deviation, CV, IQR

Skewness, Kurtosis

Quartiles, Deciles, Percentiles, Z-Score

# Inferential Statistics

Hypothesis Testing

Z-Test, T-Test

Confidence Interval

Central Limit Theorem

Chi-Square Test


# 📊 Visualizations

Histogram + KDE

Boxplot

Normal distribution curves

Bar charts for tests


# 🛠 Built With

Python · Streamlit · NumPy · Pandas · Seaborn · Matplotlib · SciPy


# ▶ Run the App
pip install streamlit numpy pandas seaborn matplotlib scipy
streamlit run app.py

# 💡 Why This App?

Because statistics becomes powerful when theory meets visualization.
This app helps you see what the formulas actually do.
